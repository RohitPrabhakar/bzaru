# Quick Reference: Breaking Changes

This is a quick-lookup guide for the most common code changes you'll need to make during migration.

---

## 🔥 Firebase Breaking Changes

### Firebase Initialization
```dart
// ❌ OLD (Firebase 1.x)
import 'package:firebase_core/firebase_core.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp();
  runApp(MyApp());
}

// ✅ NEW (Firebase 4.x+)
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart'; // Generated by: flutterfire configure

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(MyApp());
}
```

**Action Required:** Run `flutterfire configure` to generate `firebase_options.dart`

### Firebase Auth

```dart
// ❌ OLD
import 'package:firebase_auth/firebase_auth.dart';

// Get current user (was a method)
FirebaseUser? user = await FirebaseAuth.instance.currentUser();

// Sign in
AuthResult result = await FirebaseAuth.instance.signInWithEmailAndPassword(
  email: email,
  password: password,
);
FirebaseUser user = result.user;

// Get ID token
String token = await user.getIdToken();


// ✅ NEW
import 'package:firebase_auth/firebase_auth.dart';

// Get current user (now a property)
User? user = FirebaseAuth.instance.currentUser;

// Sign in
UserCredential result = await FirebaseAuth.instance.signInWithEmailAndPassword(
  email: email,
  password: password,
);
User? user = result.user;

// Get ID token
String? token = await user?.getIdToken();
```

**Key Changes:**
- `FirebaseUser` → `User`
- `AuthResult` → `UserCredential`
- `currentUser()` method → `currentUser` property
- Return types are now nullable

### Cloud Firestore

```dart
// ❌ OLD
import 'package:cloud_firestore/cloud_firestore.dart';

// Query documents
QuerySnapshot snapshot = await FirebaseFirestore.instance
    .collection('users')
    .get();

// Iterate documents
snapshot.documents.forEach((doc) {  // ← documents
  var data = doc.data;               // ← data is property
  String name = data['name'];
});

// Get document
DocumentSnapshot doc = await FirebaseFirestore.instance
    .collection('users')
    .document('userId')              // ← document() method
    .get();


// ✅ NEW
import 'package:cloud_firestore/cloud_firestore.dart';

// Query documents
QuerySnapshot snapshot = await FirebaseFirestore.instance
    .collection('users')
    .get();

// Iterate documents
snapshot.docs.forEach((doc) {       // ← docs
  var data = doc.data() as Map<String, dynamic>?;  // ← data() is method
  String? name = data?['name'];
});

// Get document
DocumentSnapshot doc = await FirebaseFirestore.instance
    .collection('users')
    .doc('userId')                  // ← doc() method
    .get();
```

**Key Changes:**
- `snapshot.documents` → `snapshot.docs`
- `doc.data` → `doc.data()` (now a method)
- `.document(id)` → `.doc(id)`
- Need explicit type casting
- Proper null safety

### Firebase Storage

```dart
// ❌ OLD
import 'package:firebase_storage/firebase_storage.dart';

// Upload file
StorageReference ref = FirebaseStorage.instance
    .ref()
    .child('images/photo.jpg');

StorageUploadTask uploadTask = ref.putFile(file);
StorageTaskSnapshot snapshot = await uploadTask.onComplete;  // ← onComplete

if (snapshot.error == null) {
  String downloadUrl = await snapshot.ref.getDownloadURL();
}


// ✅ NEW
import 'package:firebase_storage/firebase_storage.dart';

// Upload file
Reference ref = FirebaseStorage.instance
    .ref()
    .child('images/photo.jpg');

UploadTask uploadTask = ref.putFile(file);
TaskSnapshot snapshot = await uploadTask;  // ← Direct await, no onComplete

String downloadUrl = await snapshot.ref.getDownloadURL();
```

**Key Changes:**
- `StorageReference` → `Reference`
- `StorageUploadTask` → `UploadTask`
- `uploadTask.onComplete` → `await uploadTask` (direct await)
- No more `snapshot.error` - use try/catch

## 🎯 Null Safety Changes

### Constructor Parameters

```dart
// ❌ OLD (Pre-null safety)
class MyWidget extends StatelessWidget {
  const MyWidget({
    Key key,                    // ← No null indicator
    @required this.title,       // ← @required annotation
    this.subtitle,
  }) : super(key: key);

  final String title;
  final String subtitle;
}


// ✅ NEW (Null safety)
class MyWidget extends StatelessWidget {
  const MyWidget({
    super.key,                  // ← super parameter (cleaner)
    required this.title,        // ← required keyword
    this.subtitle,
  });

  final String title;
  final String? subtitle;       // ← Nullable type
}

// Alternative (if you need to use key):
class MyWidget extends StatelessWidget {
  const MyWidget({
    Key? key,                   // ← Nullable Key
    required this.title,
    this.subtitle,
  }) : super(key: key);

  final String title;
  final String? subtitle;
}
```

**Key Changes:**
- `Key key` → `Key? key` or `super.key`
- `@required` → `required`
- Optional parameters need `?` if they can be null

---

### Nullable Types

```dart
// ❌ OLD
String getUserName(User user) {
  return user.name;  // Could crash if name is null
}

void processUser() {
  User user = getUser();
  if (user != null) {
    print(user.name);
  }
}


// ✅ NEW
String? getUserName(User? user) {
  return user?.name;  // Safe navigation
}

void processUser() {
  User? user = getUser();
  if (user != null) {
    print(user.name);  // Smart cast inside if
  }

  // Or use ?.
  print(user?.name ?? 'Unknown');
}

// If you're CERTAIN it's not null:
String getUserNameForced(User user) {
  return user.name!;  // Force unwrap (use sparingly!)
}
```

**Key Operators:**
- `?` = Nullable type (can be null)
- `?.` = Safe navigation (if null, returns null)
- `??` = Null coalescing (provide default)
- `!` = Force unwrap (crashes if null - use carefully!)

### Late Initialization

```dart
// ❌ OLD
class MyService {
  DatabaseService _db;  // Initialized later

  void init() {
    _db = DatabaseService();
  }
}


// ✅ NEW
class MyService {
  late DatabaseService _db;  // Will be initialized before use

  void init() {
    _db = DatabaseService();
  }
}

// Or make it nullable:
class MyService {
  DatabaseService? _db;

  void init() {
    _db = DatabaseService();
  }

  void use() {
    _db?.doSomething();  // Safe
  }
}
```

## 📦 Package-Specific Changes

### connectivity → connectivity_plus

```dart
// ❌ OLD
import 'package:connectivity/connectivity.dart';

final connectivity = Connectivity();
var result = await connectivity.checkConnectivity();

if (result == ConnectivityResult.mobile) {
  // Mobile network
}


// ✅ NEW
import 'package:connectivity_plus/connectivity_plus.dart';

final connectivity = Connectivity();
var result = await connectivity.checkConnectivity();

if (result == ConnectivityResult.mobile) {
  // Mobile network - same API!
}
```

**Key Changes:**
- Package name changed
- API is mostly compatible
- Just update the import

### flutter_slidable (Major API Change)

```dart
// ❌ OLD (0.5.x)
Slidable(
  actionPane: SlidableDrawerActionPane(),
  actionExtentRatio: 0.25,
  child: ListTile(title: Text('Item')),
  actions: <Widget>[
    IconSlideAction(
      caption: 'Delete',
      color: Colors.red,
      icon: Icons.delete,
      onTap: () => _delete(),
    ),
  ],
  secondaryActions: <Widget>[
    IconSlideAction(
      caption: 'Archive',
      color: Colors.blue,
      icon: Icons.archive,
      onTap: () => _archive(),
    ),
  ],
)


// ✅ NEW (3.x)
Slidable(
  key: ValueKey(item.id),
  startActionPane: ActionPane(
    motion: ScrollMotion(),
    children: [
      SlidableAction(
        onPressed: (context) => _delete(),
        backgroundColor: Colors.red,
        foregroundColor: Colors.white,
        icon: Icons.delete,
        label: 'Delete',
      ),
    ],
  ),
  endActionPane: ActionPane(
    motion: ScrollMotion(),
    children: [
      SlidableAction(
        onPressed: (context) => _archive(),
        backgroundColor: Colors.blue,
        foregroundColor: Colors.white,
        icon: Icons.archive,
        label: 'Archive',
      ),
    ],
  ),
  child: ListTile(title: Text('Item')),
)
```

**Key Changes:**
- `actions`/`secondaryActions` → `startActionPane`/`endActionPane`
- `IconSlideAction` → `SlidableAction`
- `ActionPane` requires `motion` parameter
- `onTap` → `onPressed` (takes BuildContext)

### image_picker

```dart
// ❌ OLD
import 'package:image_picker/image_picker.dart';

final picker = ImagePicker();
final pickedFile = await picker.getImage(
  source: ImageSource.gallery,
);

if (pickedFile != null) {
  File imageFile = File(pickedFile.path);
}


// ✅ NEW
import 'package:image_picker/image_picker.dart';

final picker = ImagePicker();
final XFile? pickedFile = await picker.pickImage(
  source: ImageSource.gallery,
);

if (pickedFile != null) {
  File imageFile = File(pickedFile.path);
}
```

**Key Changes:**
- `getImage()` → `pickImage()`
- Return type is `XFile?` (was `PickedFile?`)
- Path usage is the same

## 🚨 Watch Out For

### 1. Don't Overuse Force Unwrap (!)
```dart
// ⚠️ DANGEROUS - Will crash if null
String name = user!.name!;

// ✅ BETTER - Safe
String? name = user?.name;

// ✅ WITH DEFAULT
String name = user?.name ?? 'Unknown';
```

### 2. Check Firestore Data Casting
```dart
// ⚠️ MIGHT FAIL
var data = doc.data();
String name = data['name'];

// ✅ SAFER
var data = doc.data() as Map<String, dynamic>?;
String? name = data?['name'] as String?;
```

### 3. Async currentUser
```dart
// ❌ OLD - Was async
User? user = await FirebaseAuth.instance.currentUser();

// ✅ NEW - Now synchronous property
User? user = FirebaseAuth.instance.currentUser;
```
